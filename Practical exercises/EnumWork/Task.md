Задача: Диагностический контроллер кофемашины
Контекст
Разработать консольную утилиту для тестирования заварочного узла (brew group) автоматической кофемашины. Программа должна позволять переключать состояния механизма через консольный интерфейс и обрабатывать логику смены состояний.

Требования к реализации
1. Перечисление (enum BrewGroupState)
Создать перечисление BrewGroupState со следующими этапами работы и явными числовыми значениями:

Standby = 10 — Ожидание

WarmingUp = 20 — Нагрев термоблока

Grinding = 30 — Помол зерен

Brewing = 40 — Экстракция/Варка

Rinsing = 50 — Промывка системы

MechanismJammed = 99 — Заклинивание механизма

2. Класс контроллера (class CoffeeMachineDiagnostics)
Класс должен содержать следующую функциональность:

Поля:

Поле для хранения текущего состояния механизма (значение по умолчанию — BrewGroupState.Standby).

Методы:

Метод вывода всех доступных команд. Программно извлекает список имен элементов BrewGroupState и выводит их в консоль.

Метод SetState(string input). Безопасно преобразует введенную строку в соответствующее значение enum (без учета регистра). При некорректном вводе состояние принудительно переводится в MechanismJammed.

Метод ExecuteCurrentState(). Использует конструкцию switch для проверки текущего состояния и выводит в консоль информацию об активном процессе (например, для Grinding — «Вращение жерновов...», для MechanismJammed — предупреждающее сообщение).

3. Точка входа (Main)
Создать экземпляр класса CoffeeMachineDiagnostics.

Реализовать бесконечный цикл while (true) для работы CLI-интерфейса.

Внутри цикла:

Вывести текущий статус механизма.

Вывести список всех доступных состояний.

Запросить ввод нового состояния (предусмотреть команду exit для завершения работы программы).

Передать полученную строку в метод SetState.

Вызвать метод ExecuteCurrentState для выполнения логики текущего состояния.
